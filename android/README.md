# پیام‌نگار امن — نسخهٔ Android

این پوشه برای نسخهٔ بومی Android است و مستقل از نسخهٔ آفلاین HTML در ریشهٔ مخزن نگهداری می‌شود.

## وضعیت

- سورس Android باید در این مسیر قرار بگیرد.
- گردش‌کار GitHub Actions در `.github/workflows/android-apk.yml` برای اجرای تست‌ها و ساخت APK آماده شده است.
- پس از قرار گرفتن سورس در این پوشه، push به شاخهٔ `main` ساخت APK را اجرا می‌کند.
- فایل APK در بخش Actions به‌صورت Artifact قابل دریافت خواهد بود.
- اجرای دستی Workflow با مقدار `release_tag`، APK آزمایشی را در GitHub Releases منتشر می‌کند.

## نکتهٔ امنیتی

APK فعلی در پیکربندی debug ساخته می‌شود و با کلید debug امضا خواهد شد. این خروجی صرفاً برای آزمون خصوصی است، نه انتشار نهایی. برای نسخهٔ انتشار باید کلید امضای اختصاصی خارج از مخزن نگهداری و از GitHub Actions Secrets استفاده شود.

نسخهٔ آفلاین HTML در ریشهٔ مخزن نباید تغییر کند.
