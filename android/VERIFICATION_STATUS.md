# وضعیت راستی‌آزمایی — پیام‌نگار امن Android v1

آخرین به‌روزرسانی: 2026-11-02

## وضعیت فعلی

- سورس Android در شاخهٔ مستقل `android-native-v1` است.
- شاخهٔ `main` و نسخهٔ وب خارج از محدودهٔ تغییرات این مرحله باقی مانده‌اند.
- APK نوع Debug از طریق GitHub Actions ساخته می‌شود؛ موفقیت build به معنی تأیید نصب و رفتار روی گوشی واقعی نیست.
- ممیزی امنیتی مستقل انجام نشده است.

## اصلاحات انجام‌شده در این مرحله

1. درخواست مجوزهای `SEND_SMS` و `RECEIVE_SMS` مستقل از هم بررسی می‌شود؛ اگر هر کدام ناقص باشد، برنامه هر دو مجوز لازم را درخواست می‌کند.
2. درخواست مجوزهای SMS به اولین بازکردن گفتگو منتقل شد تا دریافت SMS قبل از اولین تلاش برای ارسال نیز تعیین تکلیف شود.
3. مجوز اعلان از مجوزهای SMS جدا شد و اختیاری است؛ ردکردن اعلان نباید ارسال/دریافت SMS را مسدود کند.
4. در صورت رد مجوز SMS، راهنمای داخل برنامه برای ورود به App info و فعال‌کردن Allow restricted settings نمایش داده می‌شود. برنامه ادعا نمی‌کند که می‌تواند این محدودیت سیستم‌عامل را خودکار دور بزند.
5. راهنمای README با رفتار واقعی کد و وضعیت CI به‌روزرسانی شد.

## آزمون‌های سورس

- آزمون‌های Java خالص و آزمون متقابل Java/WebCrypto قبلاً موفق گزارش شده‌اند.
- پس از تغییرات Permission باید CI دوباره اجرا و build کامل Android تأیید شود.
- این تغییرات هنوز روی گوشی واقعی آزمایش نشده‌اند.

## آزمون‌های دستگاه که نیازمند اجرای واقعی هستند

- نصب با ADB روی هر دو گوشی.
- بررسی `SEND_SMS` و `RECEIVE_SMS` در App permissions و خروجی `dumpsys package`.
- بررسی فعال‌سازی Restricted Settings در رابط کاربری دستگاه.
- ارسال و دریافت SMS واقعی، پیام چندبخشی و دریافت در پس‌زمینه.
- بررسی اعلان با مجوز روشن و خاموش.
- بررسی قفل خودکار گفتگو هنگام رفتن برنامه به پس‌زمینه.

## محدودیت انتشار عمومی

برنامه در حال حاضر Default SMS Handler نیست، در حالی که سیاست Google Play برای مجوزهای SMS محدودیت‌های جدی دارد. این موضوع مانع فنی مستقل از نصب خصوصی دو گوشی است و پیش از انتشار عمومی باید به‌صورت جداگانه حل شود. در این مرحله معماری Default SMS تغییر داده نشده است.

## محدودیت‌های امنیتی

این پروژه نمونهٔ اولیهٔ خصوصی است و ممیزی امنیتی مستقل نشده است. هیچ ادعایی مبنی بر امن‌بودن کامل، تأیید Play Protect یا تأیید سازگاری همهٔ سازندگان گوشی مطرح نمی‌شود.
